CertPilot Web API v1

WPF 和浏览器管理端复用同一应用层与持久化任务队列。

接口契约

在浏览器登录后读取 OpenAPI JSON。后端集成使用限定范围 Bearer Token；Cookie 写请求需要 CSRF token。密钥与私钥不通过 API 下载。

Authorization: Bearer <server-side-token>
Content-Type: application/json
Idempotency-Key: <unique-8-to-128-character-key>
If-Match: "revision-N"

创建配置和提交任务需 Idempotency-Key；更新或删除配置需 If-Match。Cookie 客户端从 GET /api/v1/auth/csrf 获取 token，写请求带 X-CSRF-TOKEN，登录后重新获取。

主要资源（前缀 /api/v1）

  • GET / POST /certificates：分页查询、创建配置。
  • GET / PUT / DELETE /certificates/{id}：读取、更新、停止托管。
  • POST /certificates/{id}/issuances、/renewals、/inspections：排队签发、续期、网站检测。
  • GET /jobs、/jobs/{id}：任务与结果。
  • GET / POST /credentials，PUT /credentials/{id}：凭据元数据与替换。
  • GET /system/status：Web / Worker 心跳与允许目录。
  • 管理员 Cookie：/api-tokens、/users。

在线只读查询

复用当前浏览器会话。

提交任务返回 202、jobId、Location、Retry-After。状态为 queued / running / succeeded / failed；自动重试期间为 queued。建议每 3–5 秒轮询。错误返回 Problem Details。
