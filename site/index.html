▰ CertPilot v0.1.1

让域名证书，
自动保持在线。

面向 Windows Server 的自托管 ACME 证书服务。原生 WPF 桌面管理，后台 Worker 自动续期；Web 管理端与 API 复用同一数据和任务。

体验管理端原型 →

下载 Windows WPF 完整包 →

双击 CertPilot.exe，打开原生 WPF 管理端

完整 ZIP 包含 WPF 桌面端、后台服务、Web 资源和安装脚本。根目录 CertPilot.exe 是图形入口；service/CertPilot.Service.exe 是后台宿主。单一 Windows 服务托管 Web 管理端、REST API 和续期 Worker。服务关闭浏览器后继续运行，SQLite 持久化任务，断电后恢复活动任务和挑战清理。

从验证到发布

支持 Cloudflare DNS-01（含通配符）和 HTTP-01。输出 PEM / PFX，使用原子指针切换发布版本，并分开显示“证书文件已更新”和“IIS/Nginx 已加载新证书”。

开始开发

git clone https://github.com/remixjc/CertPilot.git
cd CertPilot
npm ci --prefix web
npm run build --prefix web
dotnet test CertPilot.sln
