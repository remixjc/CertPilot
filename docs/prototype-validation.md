## 已修正的问题

1. 内嵌沙箱不允许原生表单提交，最初的保存按钮无法触发校验。改为按钮事件执行本地保存，并增加输入框 Enter 键处理。
2. 状态保存回传后，详情页曾恢复到列表。增加当前证书 ID 和详情页恢复逻辑后，实际重新验证编辑保存、暂停与签发完成，保持详情页。
3. 列表中的证书名称与域名曾处于同一行。改为分行展示，并检查桌面及窄窗口布局。

## 模拟范围及未验证内容

所有证书、DNS 授权状态、签发进度、Windows 服务状态和输出路径都是原型状态，不表示对应操作已经在系统执行。原型固定演示时间为 2026-11-16；模拟签发后的日期用于交互展示，正式版必须读取真实证书与 ARI。

移除托管流程、输出路径冲突等逻辑已编写，但本次没有逐一执行所有输入组合。生产实现仍需按实施方案中的清单验证。

以下尚未实现，也未验收：

- Windows `.exe` 管理端、Worker Service 与安装器。
- 实际服务注册、开机启动、注销后后台运行和异常恢复。
- DNS API、HTTP-01 与 Let's Encrypt Staging / Production。
- 真实 PEM/PFX、文件权限、密码加密、SQLite 和断电恢复。
- SMTP 告警、CA 协议接受、目录选择器与 IIS/Nginx 部署。

本记录仅证明所列原型交互与布局可用，不替代 Windows 服务器端的集成验收。

## v0.2 增补：Web 与 API

日期：2026-11-16。以下通过更新后的浏览器原型实际操作确认，全部为本地模拟：

| 项目 | 观察结果 |
| --- | --- |
| Web 访问设置 | 默认仅本机 HTTPS；切换内网后显示 IP、访问域名和管理证书前提 |
| 前提校验 | 未确认可信证书时阻止内网保存；端口 443 被原型的 1024–65535 范围规则阻止 |
| 模拟保存 | 满足条件后保存内网配置，浏览器监控显示对应入口；恢复本机配置后入口更新 |
| API 未认证 | 选择“未提供凭据”，查询返回模拟 HTTP 401 / UNAUTHENTICATED |
| API 已授权 | 只读身份查询证书返回 200，同样显示桌面列表已有的四张演示记录 |
| 服务状态 API | 查询 `/api/v1/system/status` 返回 Worker/Web 状态与当前模拟入口 |
| 站点检测 | 选择官方网站，显示链、域名与托管版本匹配的模拟结果 |
| 未部署新证书 | 选择网关，显示网站仍提供旧证书，与托管指纹不一致的模拟结果 |
| 检测选择保持 | 检测开始和结束后，目标域名保持所选值；换目标后清除旧结果 |
| 桌面关闭交互 | 关闭后显示 Web/API 继续运行；“浏览器查看（模拟）”可进入同一批数据的监控页 |
| 新页面窄窗口 | 352px 浏览器宽度、根内容约 305px 时无横向溢出；表单与 JSON 按宽度换行 |
| 页面错误 | 本次读取的控制台 error 列表为空 |

本轮修正了检测过程中重绘导致目标选择回到第一项的问题。示例监控账号为预设 Operator，未实现登录页面或真实权限；所有 200/401 都是界面生成的演示响应。可信证书复选框只用于体验流程，正式版必须校验证书及访问条件，不能靠用户勾选判定安全。

尚未实现真实 Kestrel 监听、HTTPS/防火墙变更、认证/CSRF/Token、远程访问、HTTP API、OpenAPI 文档生成与 TLS 网络检测。旧版“尚未实现”范围继续有效。实际服务架构和生产验收以 [Web 与 API 设计](web-api-design.md) 为准。
